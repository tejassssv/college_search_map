# 🗺️ Interactive College Search Map

An interactive college-location map built using **Python, Folium, GeoJSON, and JavaScript**. The project allows users to explore college locations on an interactive map and search for colleges using an integrated search bar.

This is my **first Python project**, created to learn how Python can be used with geographical data, interactive maps, and web-based visualization.

## 🚀 Features

* 🗺️ Interactive map of colleges across India
* 🔎 Built-in college search functionality
* 📍 Displays college locations using latitude and longitude
* 💬 College information through map popups/tooltips
* 📊 Uses structured college data stored in Python dictionaries
* 🌐 Converts college data into **GeoJSON** format
* 🧩 Uses Folium layers for organizing map data
* ⚡ JavaScript integration for handling search events
* 💾 Generates an interactive `map.html` file

## 🛠️ Technologies Used

* **Python**
* **Folium** – for creating interactive maps
* **GeoJSON** – for representing geographical data
* **JavaScript** – for handling interactive map events
* **Leaflet.js** – used internally by Folium for the interactive map
